# Stakeholder Analysis

## 1. Customer

### Responsibilities

- Submit service requests
- Provide request information
- Receive updates
- Review request resolution

### Main Needs

- Easy request submission
- Visibility into request status
- Clear communication

---

## 2. Support Agent

### Responsibilities

- Review assigned requests
- Investigate customer issues
- Update request status
- Add comments
- Resolve requests

### Main Needs

- Clear work queue
- Request prioritization
- Complete request history

---

## 3. Team Leader

### Responsibilities

- Assign requests
- Monitor workload
- Monitor SLA compliance
- Support escalations

### Main Needs

- Team visibility
- Request assignment controls
- SLA monitoring

---

## 4. Manager

### Responsibilities

- Monitor service performance
- Analyze operational indicators
- Identify process problems

### Main Needs

- Dashboards
- Reports
- SLA indicators
- Historical data

---

## 5. System Administrator

### Responsibilities

- Manage users
- Manage roles
- Maintain system configuration

### Main Needs

- User management
- Role management
- System configuration
