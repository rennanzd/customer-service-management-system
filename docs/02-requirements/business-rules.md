# Business Rules

| ID | Business Rule |
|---|---|
| BR-001 | Every service request must have a unique identifier. |
| BR-002 | Every request must have a priority. |
| BR-003 | Every request must have a status. |
| BR-004 | Only authorized users can assign requests. |
| BR-005 | Only authorized users can change request priority. |
| BR-006 | A request cannot be closed without being resolved. |
| BR-007 | Every status change must be recorded in the request history. |
| BR-008 | A customer can view requests associated with their account. |
| BR-009 | Managers can access operational reports. |
| BR-010 | Administrators are responsible for user and role management. |
