# Functional Requirements

| ID | Requirement | Priority |
|---|---|---|
| FR-001 | The system shall allow customers to create service requests. | High |
| FR-002 | The system shall generate a unique request ID. | High |
| FR-003 | The system shall allow authorized users to view service requests. | High |
| FR-004 | The system shall allow Team Leaders to assign requests to Support Agents. | High |
| FR-005 | The system shall allow authorized users to change request priority. | High |
| FR-006 | The system shall allow Support Agents to update request status. | High |
| FR-007 | The system shall allow users to add comments to requests. | Medium |
| FR-008 | The system shall maintain request history. | High |
| FR-009 | The system shall allow Managers to view service reports. | Medium |
| FR-010 | The system shall allow Administrators to manage users and roles. | High |

## Requirement Priority

### High

Requirements required for the core service request workflow.

### Medium

Requirements that improve operational visibility and usability.
