## 📌 Project Overview

The Customer Service Management System is a portfolio project designed from the perspective of a Systems Analyst.

The project addresses a fictional customer support company that currently manages service requests through emails, phone calls, and spreadsheets.

The goal is to analyze the existing business process and define a centralized system capable of managing customer service requests from creation to resolution.

---

## 🏢 Business Context

NorthStar Services is a fictional customer support company that receives a large number of customer requests every month.

The current process relies heavily on manual activities, including:

- Request registration
- Request assignment
- Priority management
- Status tracking
- Customer communication
- Performance reporting

This creates operational inefficiencies and reduces management visibility.

---

## ❗ Business Problem

The current process presents several challenges:

- Customer requests are stored in different places
- Requests can remain without an assigned agent
- Urgent requests are difficult to identify
- SLA deadlines are difficult to monitor
- Request history is fragmented
- Managers have limited reporting capabilities

---

## 🎯 Business Objectives

The proposed system aims to:

1. Centralize customer service requests
2. Improve request visibility
3. Support request prioritization
4. Improve SLA monitoring
5. Maintain request history
6. Improve operational reporting
7. Reduce manual administrative work

---

## 👥 Main Stakeholders

| Stakeholder | Responsibility |
|---|---|
| Customer | Creates and tracks service requests |
| Support Agent | Processes and resolves requests |
| Team Leader | Assigns requests and monitors operations |
| Manager | Analyzes performance and SLA indicators |
| Administrator | Manages users and system configuration |
